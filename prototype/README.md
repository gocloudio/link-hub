# 团队导航 · 交互原型

纯 HTML、CSS、JavaScript 编写，无构建步骤、无 CDN 依赖。

## 打开

直接用浏览器打开 `index.html`，或在项目根目录运行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory prototype
```

访问 http://127.0.0.1:4173 。

## 已覆盖的流程

- 12 张示例工具卡片，分类筛选、多分类关系与数量显示。
- 分类按名称排列，卡片按创建时间倒序，编辑保持原位置。
- 卡片链接在新标签页打开，独立说明弹窗。
- 浅色、深色切换与浏览器偏好保存。
- 点击“管理员登录”，在提示中进入明确标识的管理员演示。
- 右侧抽屉新增、编辑卡片，分类多选和表单校验。
- Markdown 源码、实时预览、加粗、斜体、列表、链接和代码工具。
- 删除卡片、分类新增与改名；有关联卡片的分类拒绝删除。
- 手机分类栏可收起、卡片单列，管理功能完整可用。

## 原型边界

原型只使用示例数据。修改保存在当前浏览器的 `link-hub-prototype-v1` localStorage 中，主题偏好存储为 `link-hub-theme`。删除相应存储项可恢复示例数据；浏览器限制存储时仅保持当前页面的数据。

管理员身份仅为交互演示，没有接入 Entra、Go 或 PostgreSQL。原型使用小范围的 Markdown 渲染函数，仅用于演示已要求的语法，图片与原始 HTML 不执行。正式前端按需求采用已安装的 `@uiw/react-md-editor`。

品牌标记用于示例区分，不是实际团队内容。正式实现的图标方案不增加用户必须维护的字段。
